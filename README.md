## 🚀 About me

I'm a full-stack engineer who ships **production software end-to-end** — from database schema and async APIs to polished React UIs and live deployment. Over the last year I designed and built **[Aivo](https://aivo.kg)**, a multi-tenant AI-agent platform, on my own: backend, frontend, embeddable widget, infrastructure and integrations.

- 🧠 I build **AI agents** (LLM + RAG) that answer customers automatically across Telegram, WhatsApp, Instagram and website widgets.
- ⚙️ I care about **clean architecture** — domain-driven backends, strict multi-tenant isolation, idempotent billing, background workers for heavy work.
- 🎨 I sweat the **UX details** — responsive layouts, real-time chat, smooth animations.
- 🤝 Open to **freelance & product work** — reliable, communicative, and I own the result from first commit to production.

## 🧩 Featured project — Aivo Platform

> **AI customer-support & sales agents for business.** A SaaS where companies build no-code AI agents, connect them to their channels, and let them handle conversations, capture orders and sync data — 24/7.

| | |
|---|---|
| **Backend** | FastAPI · Python 3.13 · async SQLAlchemy 2 · PostgreSQL + pgvector · Redis · ARQ worker · Alembic |
| **Frontend** | React 19 · TypeScript · Vite · Tailwind CSS v4 · TanStack Query · Zustand · Framer Motion |
| **AI / RAG** | OpenAI · Claude · Gemini · Groq · DeepSeek · hybrid search (vector + full-text + fuzzy) with Reciprocal Rank Fusion |
| **Channels** | Telegram · WhatsApp · Instagram · embeddable Web Widget (Shadow DOM) |
| **Integrations** | Google Sheets & Calendar (OAuth) · Bitrix24 · amoCRM · FreedomPay billing |
| **Infra** | Docker · Nginx · Cloudflare · VPS · CI dependency audits |
